# QA Automation Cypress — Cart & Login tests

This repository contains Cypress end-to-end tests for the demo site https://automationpratice.com.br/.

## Tests implemented
- `cypress/e2e/login.cy.js` — login scenarios:
  - Successful login
  - Invalid password
  - Invalid email

- `cypress/e2e/cart.cy.js` — shopping cart scenarios:
  - Add a product to cart and validate presence
  - Update quantity and validate updated value
  - Remove product and validate empty cart
  - Add multiple products and validate items
  - Proceed to checkout from cart

## Run locally

Install dependencies:

```bash
npm install
```

Run a single spec (headed, Chrome):

```bash
npx cypress run --headed --browser chrome --spec "cypress/e2e/cart.cy.js"
npx cypress run --headed --browser chrome --spec "cypress/e2e/login.cy.js"
```

Open interactive Test Runner:

```bash
npx cypress open
```
